# 🤖 Telegram Participant Bot

Telegram-бот для отслеживания участников мероприятия с кнопками "Участвую", "Не уверен", "Не пойду".

## 📌 Особенности

- ✅ Кнопки для выбора статуса
- ✅ Автоматическое обновление списка
- ✅ Поддержка SQLite (сохранение между перезапусками)
- ✅ Поддержка Docker
- ✅ Легко масштабируется
